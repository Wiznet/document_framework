## Summary

ESP32-W5500-SoM carries an ESP32-S3 host, external flash, power and clock
circuitry, and the W5500 hardwired TCP/IP controller — including the Ethernet front-end components —
combined on a single solder-down module.

Unlike a Linux SoM (i.MX, Sitara class), this module runs its own firmware directly on the MCU. The
carrier board only has to provide power and application I/O; the Ethernet signal chain that
customers most often get wrong is already solved on the module.

| Item | Detail |
| --- | --- |
| Positioning | Proven, stable wired Ethernet reference for ESP32 designs |
| Target users | ESP32 / ESP-IDF developers, industrial IoT, ESPHome and Home Assistant users |
| Typical applications | Industrial sensor gateway, PoE sensor node, RS485/Modbus gateway, remote monitoring, wired BLE proxy |
| Network stack | Hardwired TCP/IP (TOE) or MACRAW + LwIP |
| Compare with | [ESP32-W6300-SoM](./esp32-w6300-som) — adds IPv6 and QSPI |

## Features

- ESP32-S3 host MCU with Wi-Fi and Bluetooth LE
- [W5500](/Product/Chip/Ethernet/W5500/) hardwired TCP/IP controller
  - 8 independent hardware sockets
  - 10/100 Ethernet PHY embedded, auto-negotiation
  - SPI host interface
- Ethernet front-end circuitry integrated on the module
- Solder-down (SMT) form factor for carrier-board integration
- Supported by [`wsm_driver`](https://github.com/Wiznet/wsm_driver) as an ESP-IDF component
- Wi-Fi backup / Ethernet-first hybrid networking possible on a single module
