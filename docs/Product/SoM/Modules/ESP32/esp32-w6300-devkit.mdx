## Summary

ESP32-W6300-DevKit is the [ESP32-W6300-SoM](./esp32-w6300-som) already mounted on a carrier board,
with everything needed to power it, program it, and put it on a network.

It is the board to use when the design needs IPv6, or more throughput than SPI allows. The module,
the driver, and the firmware you develop here carry over unchanged to the production design — only
the board around the module changes.

| Item | Detail |
| --- | --- |
| Purpose | Evaluation, firmware development, demos |
| Module under test | [ESP32-W6300-SoM](./esp32-w6300-som) — ESP32-S3 + W6300, IPv4/IPv6, SPI/QSPI |
| Ships inside a product? | No. For production, design a carrier board and solder the SoM |
| Programming | USB, no external programmer required |

:::tip Which one do I need?

**DevKit** to evaluate and write firmware. **SoM** to ship. See
[Where a SoM sits](/Product/SoM/overview#where-a-som-sits) for how the two relate.

:::

## What is on the board

```text
ESP32-W6300-DevKit
├── ESP32-W6300-SoM ....... the module being evaluated
├── USB ................... power and programming
├── RJ45 .................. Ethernet connector
├── Power .................. regulator and rail selection
├── Breakout headers ...... module I/O brought out for prototyping
├── Buttons ............... reset, boot
└── LEDs .................. power, link, user
```

Everything except the module is carrier-board circuitry — the part you replace with your own design
when the product is built.

## Features

- [ESP32-W6300-SoM](./esp32-w6300-som) mounted and pre-validated
- IPv4 and IPv6 dual stack
- SPI and QSPI host interface, so both can be measured on the same board
- USB for power and firmware download, no external programmer
- RJ45 with integrated magnetics
- Module I/O broken out to headers for prototyping
- Reset and boot buttons
- Compatible with the shared [Getting Started](/Product/SoM/reference/getting-started) procedure
