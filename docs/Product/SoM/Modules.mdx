# Modules

Every module in the family is the same idea in a different combination: a host MCU, its memory and
power circuitry, and a WIZnet Ethernet chip with the complete Ethernet front end, on one solder-down
module. What changes between them is **which MCU**, **which Ethernet chip**, and **which physical
layer**.

Pick the row that matches your design, then open the module page for its pinout, electrical values,
and measured performance.

## Which module fits

Three questions narrow the list to one or two candidates.

**1. Which MCU does the product use?** The SoM replaces the MCU on the carrier board, so this is
usually decided already.

| Your MCU / Preference | Look at |
| --- | --- |
| ESP32 — or you want Wi-Fi/BLE alongside Ethernet | ESP32-W5500-SoM, ESP32-W6300-SoM |
| STM32 — or you prefer the STMicroelectronics ecosystem such as STM32CubeIDE and STM32Cube tools | STM32F4-W6300-SoM |
| RP2040 / RP2350, or no strong MCU preference and compact size matters | W55RP20-SoM |
| No strong MCU preference, and you want Single-Pair Ethernet (SPE) | T1L-55 / T1L-RP55 / T1S-RP55 modules |

**2. Does it need IPv6?**

| Requirement | Chip | Modules |
| --- | --- | --- |
| IPv4 only | [W5500](/Product/Chip/Ethernet/W5500/) | ESP32-W5500-SoM, W55RP20-SoM |
| IPv4 and IPv6 | [W6300](/Product/Chip/Ethernet/W6300/) | ESP32-W6300-SoM, STM32F4-W6300-SoM |

**3. What is the cable?**

| Cabling | Physical layer | Modules |
| --- | --- | --- |
| Standard RJ45, in a rack or a cabinet | 10/100 | All RJ45 modules above |
| Two wires, long run to a field sensor | 10BASE-T1L | T1L-55, T1L-RP55 |
| Two wires, several nodes on one bus | 10BASE-T1S | T1S-RP55 |

Powering the node over the same cable is a carrier-board choice, not a module choice — pair any
module with **WIZPoE-SD** or **WIZPoE-RJ45**.

## Other ways to slice the lineup

The sidebar groups modules by host platform, because that is usually where a design starts. The same
products, viewed along other axes:

### By host platform

| Host | Toolchain | Modules |

| ESP32-S3 | ESP-IDF / Arduino / ESPHome | ESP32-W5500-SoM, ESP32-W6300-SoM |
| STM32F4 | STM32 HAL / CubeIDE | STM32F4-W6300-SoM |
| RP2040 / RP2350 | Pico SDK, or pre-loaded S2E firmware | W55RP20-SoM, T1L-55 / T1L-RP55, T1S-RP55 |

### By Ethernet chip

| Chip | IP version | Interface | Modules |
| --- | --- | --- | --- |

### By application

| Application | Why these | Modules |
| --- | --- | --- |
| Wi-Fi + wired hybrid | Ethernet-first with Wi-Fi backup, wired BLE proxy, ESPHome / Home Assistant | ESP32-W5500-SoM, ESP32-W6300-SoM |
| Industrial IPv6 | Dual-stack requirement on an STM32 design | STM32F4-W6300-SoM, ESP32-W6300-SoM |

| PoE-powered node | Pair any module with a WIZPoE module on the carrier board | Any, plus WIZPoE-SD / WIZPoE-RJ45 |

## How to read a module page

Every module page follows the same section order, so two modules can be compared by scrolling to the
same place on both pages.

```text
Summary ................ positioning, target users, applications
Features ............... what the module integrates
Hardware Specification . key specs · block diagram · pinout · operating condition
Performance ............ measured numbers, always with test conditions
Documentation .......... datasheet, design guide, manual
Software Resources ..... driver · examples · tools   (tabbed)
Hardware Resources ..... schematic · footprint · 3D · dimension · part list
Test & Certification ... CE / FCC / KC
Related Products ....... EVB, PoE, sibling modules
Reference Guides ....... links into the shared Reference section
How to buy
Revision History
```

A section that has no data yet is kept in place with `TBD` rather than deleted — the page shape stays
comparable across the lineup, and it is visible which data is still outstanding.

:::info Performance numbers

A throughput or power figure is only published together with the conditions it was measured under
(SDK version, driver version, interface clock, payload size, socket count, measurement point).
A bare number is not comparable between modules and must not be added.

:::
