## Overview

A compact module built on the WIZnet W55RP20. The onboard Hardwired TCP/IP engine handles all network processing in silicon, freeing the MCU core entirely for application logic. With Serial-to-Ethernet firmware pre-loaded out of the box, the module can be deployed directly into industrial equipment — no additional firmware development required.

## Specifications

| Item | Specification |
| --- | --- |
| Type | Serial-to-Ethernet System-on-Module |
| Main device | W55RP20: dual-core Arm Cortex-M0+ MCU up to 133 MHz, integrated W5500, and 2 MB flash |
| Ethernet | 10/100 Mbps Ethernet, IPv4 |
| Host interface | UART or SPI, selected by `SPI_IF_SEL` |
| Serial interfaces | Up to two TTL UART channels with full modem control (TXD, RXD, RTS, CTS, DTR, DSR) |
| Serial protocols | MQTT / MQTTS, SSL/TLS, Modbus RTU/ASCII |
| Configuration | Serial AT commands or the Configuration Tool; WIZ VSP (Virtual Serial Port) supported |
| Debug | SWD and a separate Debug UART |
| USB | Native USB signals exposed on the module interface |
| On-module clocks | 12 MHz oscillator (MCU core) + 25 MHz crystal (Ethernet PHY) — no external clock required |
| Supply | 3.3 V single rail; the 1.1 V core rail is generated by the W55RP20 internal regulator |
| Operating temperature | −40 ℃ ~ +85 ℃ |
| MAC address | Unique WIZnet MAC address pre-assigned |
| Size | 18.3 × 26.15 mm |
| Pin pitch | 1.1 mm |
| Module interface | 70-pin castellated edge interface (23 / 12 / 23 / 12 across the four sides) |

## Custom Firmware Service

EOE-W55RP20 supports tailored firmware and protocol customization through WIZnet Custom Service.

Example applications:

- Serial-to-Ethernet conversion
- Up to two serial ports; the module pins are TTL, so RS-232 and RS-422/485 need a transceiver on the carrier board
- Modbus RTU and Modbus TCP
- TCP, UDP, MQTT, HTTP/S, and TLS/SSL
- Serial baud rate up to 4 Mbps
