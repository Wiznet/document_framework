## Overview

WIZnet **Ethernet Offload Engine (EOE) modules** combine an application processor with a dedicated Hardwired TCP/IP controller. Network processing is handled in silicon, reducing software complexity and leaving the main processor available for application logic.

The family covers ready-to-use Serial-to-Ethernet operation and dual-connectivity designs that combine wired Ethernet with Wi-Fi and Bluetooth LE.
