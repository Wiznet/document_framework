## Overview

EOE-W55-EVB is the evaluation platform for the EOE-W55 module. The definition remains provisional until the evaluation-board hardware is released.

| Item | Specification |
| --- | --- |
| Supported module | EOE-W55 |
| Ethernet connector | RJ45 jack with integrated magnetics |
| USB | USB Type-C connected to the ESP32-S3 native USB interface |
| Power | On-board generation of the 3.3 V module rail |
| Expansion | GPIO, ADC, I2C, SPI, UART0, 3.3 V, and GND |
| Controls | Reset and boot controls |
| Indicators | Power and Ethernet status indicators |

:::caution
Confirm the input-voltage range and connector assignment against the released schematic before powering production hardware.
:::
