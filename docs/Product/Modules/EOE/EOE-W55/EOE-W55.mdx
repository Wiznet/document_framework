## Overview

A dual-connectivity module combining the Espressif ESP32-S3 and WIZnet W5500, delivering both wireless (Wi-Fi/BLE) and wired Hardwired TCP/IP Ethernet in a single design. Compatible with major development frameworks — ESP-IDF, Arduino, and Zephyr — enabling fast design adoption across a wide range of projects.

## Specifications

| Item | Specification |
| --- | --- |
| Type | Ethernet, Wi-Fi, and Bluetooth LE System-on-Module |
| MCU | ESP32-S3: dual-core Xtensa LX7 up to 240 MHz |
| Ethernet controller | W5500 Hardwired TCP/IP controller |
| Controller connection | SPI connection between ESP32-S3 and W5500 |
| Hardwired TCP/IP | TCP, UDP, ICMP, IPv4, ARP, IGMP, PPPoE; 8 sockets; 32 KB TX/RX buffer |
| Ethernet | 10/100 Mbps Ethernet, IPv4 |
| Wireless connectivity | Wi-Fi 4 / 802.11 b/g/n, 2.4 GHz and Bluetooth LE |
| Development frameworks | ESP-IDF, Arduino, and Zephyr |
| External interfaces | GPIO, ADC, I2C, SPI, USB, and UART0 |
| Debug | Native USB and UART0 |
| Antenna connector | U.FL connector for Wi-Fi and Bluetooth LE |
| Supply | 3.3 V single rail |
| Size | 18.3 × 26.15 mm |
| Pin pitch | 1.1 mm |
