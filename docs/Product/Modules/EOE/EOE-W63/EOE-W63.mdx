## Overview

A dual-connectivity module combining the Espressif ESP32-S3 and WIZnet W6300, delivering both wireless (Wi-Fi/BLE) and wired IPv4/IPv6 Hardwired TCP/IP Ethernet in a single design. Compatible with major development frameworks — ESP-IDF, Arduino, and Zephyr — enabling fast design adoption across a wide range of projects.

## Specifications

| Item | Specification |
| --- | --- |
| Type | Ethernet, Wi-Fi, and Bluetooth LE System-on-Module |
| MCU | ESP32-S3: dual-core Xtensa LX7 up to 240 MHz |
| Ethernet controller | W6300 Hardwired TCP/IP controller with IPv4/IPv6 support |
| Controller connection | Dedicated Quad-SPI connection between ESP32-S3 and W6300 |
| Ethernet | 10/100 Mbps Ethernet |
| Wireless connectivity | Wi-Fi 4 / 802.11 b/g/n, 2.4 GHz and Bluetooth LE |
| External interfaces | GPIO, ADC, I2C, SPI, USB, and UART0 |
| Debug | Native USB and UART0 |
| Antenna connector | U.FL connector for Wi-Fi and Bluetooth LE |
| Supply | 3.3 V single rail |
| Module interface | Two 1 × 23 signal headers and one 1 × 12 Ethernet MDI header |
