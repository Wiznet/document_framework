## Specifications

| Item | Specification |
| --- | --- |
| Type | Serial-to-Ethernet System-on-Module |
| Main device | W55RP20 SiP: RP2040 MCU, W5500 hardwired TCP/IP controller, and 2 MB flash |
| Ethernet | 10/100 Mbps Ethernet |
| Host interface | UART or SPI, selected by `SPI_IF_SEL` |
| Serial interfaces | Two UART channels with modem-control signals |
| Debug | SWD and Debug UART |
| USB | Native USB signals are exposed on the module interface |
| Supply | 3.3 V single rail |
| Module interface | 70-pin castellated edge interface |
