## Overview

## Specifications

| Item | Specification |
| --- | --- |
| Type | Ethernet, Wi-Fi, and Bluetooth LE System-on-Module |
| Main devices | ESP32-S3 and W6300 hardwired TCP/IP controller |
| Controller connection | Dedicated Quad-SPI connection between ESP32-S3 and W6300 |
| Ethernet | 10/100 Mbps Ethernet |
| Wireless connectivity | Wi-Fi 802.11 b/g/n and Bluetooth LE |
| External interfaces | GPIO, ADC, I2C, SPI, USB, and UART0 |
| Debug | Native USB and UART0 |
| Antenna connector | U.FL connector for Wi-Fi and Bluetooth LE |
| Supply | 3.3 V single rail |
| Module interface | Two 1 × 23 signal headers and one 1 × 12 Ethernet MDI header |
