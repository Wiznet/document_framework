## Overview

The **EOE-55RPL** is a compact Single Pair Ethernet (SPE) combo module that integrates the WIZnet **W55RP20** with a **10/100BASE-TX to 10BASE-T1L media converter** based on Analog Devices **ADIN1200** and **ADIN1100**.

The W55RP20 combines a dual-core Arm Cortex-M0+ MCU with the W5500 Hardwired TCP/IP Ethernet Offload Engine, while the ADIN1200 and ADIN1100 provide the Ethernet media conversion between conventional 10/100BASE-TX Ethernet and 10BASE-T1L Single Pair Ethernet.

The EOE-55RPL is designed as a solder-down module for integration into a customer carrier board. It operates from a single 3.3 V supply and includes the required clock sources for both the W55RP20 and the 10BASE-T1L PHY.

## 10BASE-T1L Interface

The EOE-55RPL includes the required 10BASE-T1L MDI termination circuitry.

For stable operation and improved protection, the use of an external **Common-Mode Choke (CMC)** and appropriate protection components on the carrier board is recommended.

Refer to the EOE-55RPL evaluation board schematic for the recommended external MDI implementation.

## Interfaces

EOE-55RPL provides the following external interfaces for carrier-board integration:

* UART or SPI host interface
* Two UART channels when using S2E firmware
* Native USB interface for RP2040 BOOTSEL firmware upload
* SWD debug interface
* Reset and boot control signals
* 10BASE-T1L MDI interface
* Ethernet link and status outputs

The following PHY management signals are used internally and are not exposed through the module interface:

| Signal | Function                                 | W55RP20 GPIO |
| ------ | ---------------------------------------- | ------------ |
| MDC    | ADIN1100 / ADIN1200 SMI management clock | GP27         |
| MDIO   | ADIN1100 / ADIN1200 SMI management data  | GP28         |

## Control and Status Signals

Key control signals include:

* `RSTn` — Active-low module reset
* `RP_BOOT` — RP2040 BOOTSEL control
* `FW_BOOT` — S2E firmware boot control
* `FACT_RSTn` — Factory reset
* `HW_TRIG` — AT command mode trigger
* `DEBUG` — Debug interface
* `SPI_IF_SEL` — Host interface selection
* `UART0_IF_SEL`
* `UART1_IF_SEL`

Ethernet status signals include:

* `LINKn` — Ethernet link status, active low
* `LED_0` — TBD
* `LED_1` — TBD

No indicator LEDs are mounted on the module. LEDs and appropriate current-limiting resistors should be implemented on the carrier board if visual status indication is required.

## Firmware

The W55RP20 can be programmed through its native USB interface or SWD interface.

When the W55RP20 enters BOOTSEL mode by asserting `RP_BOOT` low during reset, firmware can be uploaded through the native USB `D_P` and `D_N` signals.

S2E (Serial-to-Ethernet) firmware may be used to provide UART-to-Ethernet functionality and associated control interfaces.
