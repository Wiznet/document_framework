:::warning
**The RS-232 and RS-422/485 versions of WIZ550S2E have been discontinued.**

This applies only to the WIZ550S2E-232 and WIZ550S2E-485/422 interface board versions.

The base **WIZ550S2E (TTL) module is still available for purchase**. See the [WIZ550S2E](WIZ550S2E.md) page for the current product.
:::

## Product Status

| Item | Serial Interface | Line Driver | Status |
| ---- | ---------------- | ----------- | ------ |
| [WIZ550S2E](WIZ550S2E.md) (base module) | 1xTTL(3.3V) | - | **Active** |
| WIZ550S2E-232 interface board (WIZ550S2E-232-EVB) | 1xRS232 | SP3232EBEY | Discontinued |
| WIZ550S2E-485/422 interface board (WIZ550S2E-485/422-EVB) | 1xRS422/485 | SP3485EN | Discontinued |
