EOE-W55RP20 Datasheet [KO]

개요​

본 문서는 EOE-W55RP20의 하드웨어 사양서입니다. EOE-W55RP20는 라즈베리파이 RP2040 듀얼코어 MCU와 W5500 하드와이어드 TCP/IP(Ethernet Offload Engine) 컨트롤러, 2 MB 플래시를 하나의 패키지에 통합한 WIZnet W55RP20 기반의 시리얼 to 이더넷 System-on-Module(SoM) 입니다.

EOE-W55RP20는 고객 캐리어 보드에 실장하는 솔더다운 모듈로, 이더넷 MDI 페어와 2채널 UART, SPI 호스트 인터페이스, USB, SWD를 70핀 캐슬레이션 엣지 인터페이스로 인출합니다. RJ45 잭과 USB Type-C, DC 잭, 헤더가 포함된 평가용 보드가 필요하시면 EOE-W55RP20-EVB 문서를 참고하십시오.

note

EOE-W55RP20는 완제품 보드가 아니라 모듈입니다. RJ45 잭, USB 커넥터, DC 잭, 푸시 버튼, 3.3V 레귤레이터가 모듈에 포함되어 있지 않으며 이는 모두 캐리어 보드의 몫입니다. 모듈은 3.3V 전원을 직접 공급받아 동작합니다.

주요 특징​

  • W55RP20 기반 모듈 (RP2040 듀얼코어 Arm Cortex-M0+ MCU + W5500 하드와이어드 TCP/IP 코어 + 2 MB 플래시)
    • 하드와이어드 TCP/IP 프로토콜: TCP, UDP, ICMP, IPv4, ARP, IGMP, PPPoE
  • 10/100 Mbps 이더넷, MDI 프런트엔드(종단·직렬 매칭·밴드갭 기준 저항) 모듈 내장 — 캐리어 보드에는 외장 RJ45 마그네틱만 추가하면 됩니다
  • 풀 모뎀 컨트롤을 지원하는 2채널 UART (RX / TX / RTS / CTS / DSR / DTR)
  • SPI_IF_SEL 핀으로 선택하는 UART 또는 SPI 호스트 인터페이스
  • 채널별 상태 출력: STATUS0_PHY, STATUS0_TCP, STATUS1_TCP
  • 이더넷 PHY 상태 출력: LINK, ACT, SPD, DUP — 각 신호는 330 Ω 직렬 저항을 통해 모듈 상의 녹색 LED도 함께 구동합니다
  • 클럭 내장: RP2040 코어용 12 MHz 오실레이터, 이더넷 PHY용 25 MHz 크리스털 — 외부 클럭이 필요 없습니다
  • 단일 3.3V 전원, 1.1V 코어 레일은 W55RP20 내부 레귤레이터가 생성
  • 엣지 인터페이스로 인출된 제어 핀: RSTn, RP_BOOT(RP2040 BOOTSEL), FW_BOOT(S2E 펌웨어 부트), FACT_RSTn(공장 초기화), HW_TRIG(AT 커맨드 모드), DEBUG
  • 인터페이스 선택 핀: SPI_IF_SEL, UART0_IF_SEL, UART1_IF_SEL
  • BOOTSEL 모드 펌웨어 업로드용 네이티브 USB (D_P / D_N)
  • SWD 디버그 포트 (SWCLK / SWD)
  • 4면 70핀 캐슬레이션 엣지 인터페이스

caution

모듈의 모든 I/O는 3.3V TTL이며 5V 톨러런트가 아닙니다. 5V 호스트 신호는 캐리어 보드에서 레벨 시프트하십시오.

전원​

모듈은 48 / 49 / 50번 핀으로 단일 3.3V를 입력받습니다. 1.1V 코어 레일은 W55RP20 내부 레귤레이터가 생성하며 모듈 내부에서 디커플링되므로, 캐리어 보드에 별도의 코어 전원이나 추가 레귤레이터가 필요하지 않습니다.

3.3V 레일 디커플링은 모듈에 내장되어 있습니다. 캐리어 보드에서는 모듈의 3.3V 핀 가까이에 벌크 커패시터를 배치하고 GND 핀까지의 리턴 경로를 짧게 유지하십시오.

리셋​

RSTn은 액티브 로우이며, 모듈 내부에서 4.7 kΩ 저항으로 3.3V에 풀업되고 RC 지연 커패시터가 연결되어 있습니다. 51번 핀(우측)과 62번 핀(상단) 양쪽에서 사용할 수 있으며 두 핀은 같은 네트입니다. 캐리어 보드에서 리셋을 구동하지 않는다면 두 핀 모두 개방해도 무방합니다.

클럭​

이더넷 MDI 인터페이스​

모듈에는 W5500 아날로그 프런트엔드가 모두 구현되어 있습니다 — 49.9 Ω 1% 차동 종단, 각 MDI 라인의 3.3 Ω 직렬 매칭 저항, 12.4 kΩ 1% 밴드갭 기준 저항. 캐리어 보드에서는 RJ45 마그네틱 (또는 마그네틱 일체형 RJ45 잭)과 케이블 측 종단만 제공하면 됩니다.

note

상태 LED 신호​

LINK, ACT, SPD, DUP는 W5500 PHY가 직접 구동하며, 각각 330 Ω 저항을 통해 모듈 상의 녹색 LED를 이미 구동하고 있습니다. 동일한 신호가 엣지 인터페이스로도 인출되어 캐리어 보드에서 재현할 수 있습니다.

모듈 핀신호표시 내용
47LINK이더넷 링크 연결됨
46ACT송수신 활동
38SPD100 Mbps(어서트) / 10 Mbps

note

캐리어 보드에서 LED를 추가로 붙일 때는 모듈 LED가 이미 같은 PHY 핀에서 전류를 끌고 있음을 감안해 직렬 저항 값을 정하십시오.

USB 인터페이스​

D_P(19번 핀)와 D_N(18번 핀)은 W55RP20의 네이티브 USB 라인이며, 모듈에는 USB-to-UART 브리지가 없습니다. 캐리어 보드에서 90 Ω 차동 페어로 배선하고 통상의 직렬 종단 저항과 USB 커넥터를 배치하십시오.

USB 인터페이스는 W55RP20이 BOOTSEL 모드(리셋 시 RP_BOOT 로우)로 진입한 후 펌웨어를 업로드·업데이트하는 데 사용합니다. 자세한 방법은 아래 매뉴얼 항목의 FW 업데이트 가이드를 참고하십시오.
