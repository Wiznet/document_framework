EOE-W63 Datasheet [KO]

개요​

본 문서는 EOE-W63의 하드웨어 사양서입니다. EOE-W63는 Espressif ESP32-S3 Wi-Fi/BLE MCU와 WIZnet W6300 하드와이어드 TCP/IP(Ethernet Offload Engine) 컨트롤러를 전용 Quad-SPI 버스로 연결한 이더넷 + Wi-Fi/BLE System-on-Module(SoM) 입니다.

EOE-W63는 고객 캐리어 보드에 실장하는 솔더다운 모듈로, ESP32-S3의 GPIO / ADC / I2C / SPI / USB / UART 신호와 이더넷 MDI 페어를 3개의 헤더로 인출합니다. 평가용 보드가 필요하시면 EOE-W63-EVB 문서를 참고하십시오.

note

EOE-W63는 완제품 보드가 아니라 모듈입니다. RJ45 잭, USB 커넥터, DC 잭, 푸시 버튼, 3.3V 레귤레이터가 모듈에 포함되어 있지 않으며 이는 모두 캐리어 보드의 몫입니다. 모듈은 3.3V 전원을 직접 공급받아 동작합니다.

주요 특징​

  • 듀얼 컨트롤러 구성: ESP32-S3 (Wi-Fi 802.11 b/g/n + Bluetooth LE, 듀얼코어 Xtensa LX7 MCU, QFN56)
    • W6300 하드와이어드 TCP/IP 이더넷 컨트롤러 (LQFP48)
    • W6300 하드와이어드 TCP/IP 프로토콜: TCP, UDP, ICMP, IPv4, ARP, IGMP, PPPoE
  • 10/100 Mbps 이더넷, MDI 프런트엔드 모듈 내장 — 49.9 Ω 차동 종단과 12.4 kΩ 1% 밴드갭 기준 저항이 이미 실장되어 있어, 캐리어 보드에는 외장 RJ45 마그네틱만 추가하면 됩니다
  • 두 컨트롤러 간 Quad-SPI 연결 (W6300_SPI_D0–D3, W6300_SPI_CLK, W6300_SPI_nCS, W6300_nINT, W6300_nRST) — 모듈 내부 신호이며 외부로 인출되지 않습니다
  • 16 Mbit SPI 플래시 내장 (PY25Q16HB-VXH) — ESP32-S3는 플래시가 패키지에 포함되지 않은 QFN56 버전이므로 이 소자가 부트 플래시입니다
  • Wi-Fi / BLE용 U.FL 안테나 커넥터(J3) 및 모듈 내장 파이(π) 정합 회로
  • 프로그래밍·디버그용 네이티브 USB (ESP_USB_P / ESP_USB_N) — USB-to-UART 브리지 없음
  • 이더넷 PHY 상태 출력: LINKn, ACTn, SPD, DUP
  • 클럭 내장: ESP32-S3용 40 MHz 크리스털, W6300용 25 MHz 크리스털 — 외부 클럭 불필요
  • 풍부한 I/O 확장: GPIO, ADC(A0–A10), I2C(SDA / SCL), SPI(SCK / MISO / MOSI), UART0
  • 단일 3.3V 전원, 1.2V 코어 레일은 모듈 내부에서 생성
  • 신호 헤더: 1×23 두 개(J1, J2)와 이더넷 MDI용 1×12 한 개(J4)

caution

모듈의 모든 I/O는 3.3V이며 5V 톨러런트가 아닙니다. 5V 호스트 신호는 캐리어 보드에서 레벨 시프트하십시오.

전원​

모듈은 단일 3.3V(VDD33)를 입력받습니다. 모듈 내부의 인덕터가 아날로그 VDD33 도메인과 디지털 3V3 레일을 분리하며, W6300이 사용하는 1.2V 코어 레일은 모듈 내부에서 생성·디커플링 됩니다. 외부 코어 전원은 필요하지 않습니다.

caution

Wi-Fi 송신 버스트 시 대기 상태보다 훨씬 큰 전류를 소모합니다. 캐리어 보드의 3.3V 전원과 벌크 커패시터는 평균 전류가 아니라 ESP32-S3의 피크 송신 전류 기준으로 설계하십시오. 용량이 부족하면 접속 과정에서 브라운아웃 리셋으로 나타납니다.

이더넷 인터페이스​

ESP32-S3는 전용 Quad-SPI 버스로 W6300과 통신합니다. 아래 신호는 모듈 내부 신호이며 헤더로 인출되지 않습니다.

네트기능
W6300_SPI_CLKQuad-SPI 클럭
W6300_SPI_D0 – D3Quad-SPI 데이터 라인
W6300_SPI_nCS칩 셀렉트 (액티브 로우)
W6300_nINTESP32-S3로 향하는 인터럽트 (액티브 로우)
W6300_nRSTESP32-S3가 구동하는 리셋 (액티브 로우)

W6300의 병렬 호스트 데이터 버스(DAT0–DAT7)는 본 설계에서 사용하지 않으며 미연결 상태입니다.

이더넷 MDI 인터페이스​

모듈에는 W6300 아날로그 프런트엔드가 구현되어 있습니다 — 49.9 Ω 차동 종단, RSET_BG의 12.4 kΩ 1% 밴드갭 기준 저항. 캐리어 보드에서는 RJ45 마그네틱(또는 마그네틱 일체형 RJ45 잭)만 제공하면 됩니다.

J4 핀신호연결 대상
2RD_N트랜스포머 수신 페어 −
3RD_P트랜스포머 수신 페어 +
5RCT수신 센터 탭
8TCT송신 센터 탭
10TD_N트랜스포머 송신 페어 −
11TD_P트랜스포머 송신 페어 +

J4의 1, 4, 6, 7, 9, 12번 핀은 그라운드입니다.

캐리어 보드의 일반적인 RJ45 결선 (마그네틱 케이블 측):

RJ45 핀신호설명
1TXPTX+
2TXNTX−
3RXPRX+

5—미사용 (또는 PoE 페어)
6RXNRX−
7—미사용 (또는 PoE 페어)
8—미사용 (또는 PoE 페어)
note

EOE-W63는 PoE를 지원하지 않습니다. PoE가 필요하면 캐리어 보드에서 구현해야 하며, 이 경우 4/5번 핀과 7/8번 핀의 극성이 서로 반대여야 합니다.

이더넷 상태 신호​

신호헤더표시 내용
LINKnJ2이더넷 링크 연결됨 (액티브 로우)
ACTnJ2송수신 활동 (액티브 로우)
SPDJ2링크 속도 상태

신호 출력만 제공되며 모듈에는 표시용 LED가 실장되어 있지 않습니다. 필요하면 캐리어 보드에서 적절한 직렬 저항과 함께 LED를 추가하십시오.

무선 / 안테나​

Wi-Fi와 Bluetooth LE는 ESP32-S3가 담당합니다. 칩의 LNA_IN 핀에서 시작하는 RF 경로는 모듈 내장 파이(π) 정합 회로(3.3 nH 직렬 인덕터 + 1 pF 션트 커패시터)를 거쳐 U.FL / IPEX 커넥터(J3) 로 연결됩니다.

caution

안테나 커넥터와 장착된 안테나의 아래·주변에는 캐리어 보드의 구리(플레인, 트레이스, 체결 부품)가 없도록 하십시오. 인접한 금속은 정합을 틀어지게 하여 통신 거리를 떨어뜨립니다.

USB 인터페이스​

ESP_USB_P(J1 19번 핀)와 ESP_USB_N(J1 18번 핀)은 ESP32-S3의 네이티브 USB 라인이며, 모듈에는 USB-to-UART 브리지가 없습니다. 캐리어 보드에서 90 Ω 차동 페어로 배선하고 USB 커넥터를 배치하십시오.

USB 인터페이스는 ESP32-S3의 프로그래밍과 디버그에 사용합니다. U0TXD / U0RXD (J1 21, 22번 핀)로 시리얼 콘솔을 대신 사용할 수도 있습니다.

부팅 / 제어 핀​

아래 항목은 스위치나 버튼이 아니라 핀입니다. 캐리어 보드에서 점퍼, 푸시 버튼 또는 호스트 GPIO로 구동하십시오.

헤더 / 핀신호기능
J2 8번CHIP_PUESP32-S3 칩 인에이블 — 로우로 구동하면 리셋 / 셧다운 유지
J2 18번GPIO0부트 모드 선택 — 리셋 시 로우로 유지하면 ESP32-S3 시리얼 부트로더 진입

핀 배치​

전체 헤더 핀 배치 도면은 핀 배치 이미지가 준비되는 대로 추가할 예정입니다.
